## Featured Projects

View more on [GitHub](https://github.com/jkanche).

- [Kana](https://kanaverse.org/kana): Multi-modal single-cell RNA-seq analysis in the browser using WebAssembly, For more details, visit the [Kanaverse GitHub](https://github.com/kanaverse/kana) repo.
- [BiocPy](https://github.com/biocpy): Bringing Bioconductor's standardized genomic data structures to Python and support interoperable analytical workflows.
- [CellArr](https://github.com/cellarr): Cell Arrays, TileDB-backed store and PyTorch dataloaders for genomic datasets.
- [epiviz.gl](https://github.com/epiviz/epiviz.gl): High-performance genomic data visualization using WebGL and Web Workers. Also check out [epiviz.heatmap.gl](https://github.com/epiviz/epiviz.heatmap.gl) and [epiviz.scatter.gl](https://github.com/epiviz/epiviz.scatter.gl)
- [Epiviz](http://www.epiviz.org/) & [Metaviz](http://www.metaviz.org/): Interactive visualization platform for genomic and metagenomic data
